# Paper Queue

Papers discovered during web searches that need full-text PDF access for proper ingestion.

**Status key**
- `waiting` — needs PDF
- `ready` — PDF in this folder
- `done` — ingested to vault

**Source key**
- `abstract-only` — only had access to abstract / metadata
- `partial` — abstract + some figures or snippets
- `full` — read full text

**Verification**: Each DOI should be checked against CrossRef before ingestion. Entries marked `unverified` could not be confirmed.
